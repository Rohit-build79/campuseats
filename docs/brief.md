#CampusEats Brief

##What System does
Campus eat is an online odering system which is desgined for students ans food vendors on campus. Student can go thorow menu check avilable food items, view price, request for new items, place orders , and track orders while sitting in one place. Food vendors can manage their menu and prepare food as per the order.  
what is it solving

##Who will gone use it
We have 4 main Users.

###Students or Teacher
its an primary user.

- Register and login
- Browse and search food
- View food details
- Add/remove items from cart
- Place orders
- Make payments
- Track orders
- Cancel orders when allowed

###Vendor

- Manage food items
- Manage menu
- Update prices and availability
- View incoming orders
- Accept/process orders
- Update order status

###Admin

- Manage students
- Manage vendors
- Manage categories
- Monitor the system
- Manage system data

- Register : New student or teacher can Register.
- Login : Existing users can login
- Browse : All the avilable food can be browsed by users
- Search : All the listed food can be serached by users
- View : Food details and its ingridents
- Add : Request can be make for new Food to Add in menu
- Remove : Items form the cart
- Place Order : Cart will be now converte into final order
- Pay : Payment for order
- Track : Current status of the order : Order Placed -> Accepted -> Preparing -> Ready -> Completed.
- Manage : Vender can manage it accepte or reject order
- Update : Update the system data or users info or many more
- Delete : It can delete users accounts also.
